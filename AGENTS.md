# AGENTS.md - Contexte du projet

## À propos de ce dépôt

Ce dépôt contient les exercices pratiques du cours OpenClassrooms **"Apprenez les bases du langage Python"** (https://openclassrooms.com/fr/courses/7168871-apprenez-les-bases-du-langage-python).

## Structure du projet

Le cours est organisé en **3 parties** (P1, P2, P3), chacune divisée en **chapitres** (C1, C2, C3, etc.).

Pour chaque chapitre, vous trouverez deux sous-dossiers :

```
P1/
├── P1C3/
│   ├── énoncé/      # L'énoncé de l'exercice avec les instructions
│   └── correction/  # La solution/correction de l'exercice
├── P1C4/
│   ├── énoncé/
│   └── correction/
...
```

## Les exercices pratiques

Les exercices pratiques sont un élément **essentiel** de ce cours :

- À la fin de chaque chapitre, des exercices sont proposés pour renforcer les concepts appris
- Chaque exercice est accompagné d'un **énoncé** dans le cours, permettant de comprendre clairement ce qui est attendu
- Le répertoire GitHub fournit :
  - L'**énoncé** de l'exercice avec des instructions détaillées
  - Des **indications supplémentaires**, des **conseils** et des **ressources** pour réussir
  - La **correction** de l'exercice pour vérifier son travail et comparer ses réponses avec les solutions proposées

## Objectif pédagogique

Ce cours vise à apprendre les **bases du langage Python** :
- Variables et types de données
- Structures de contrôle (conditions, boucles)
- Fonctions
- Listes, dictionnaires et structures de données
- Gestion des erreurs
- Premiers pas avec les modules

## Conseils pour travailler sur les exercices

1. **Lire attentivement l'énoncé** avant de commencer à coder
2. **Essayer de résoudre l'exercice seul** avant de consulter la correction
3. **Tester son code** pour vérifier qu'il fonctionne comme attendu
4. **Comparer avec la correction** pour identifier les points d'amélioration
5. **Comprendre les différences** entre sa solution et la correction proposée

## Langue

Les agents doivent impérativement s'adresser à l'utilisateur en **français** pour les comptes-rendus et échanges.
